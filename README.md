## Descrição do Projeto

O projeto **Achados e Perdidos** tem como objetivo o desenvolvimento de uma aplicação, em arquitetura cliente-servidor, para gestão de itens perdidos e achados. A aplicação será desenvolvida em 3 etapas (Sprints), seguindo uma metodologia ágil baseada em SCRUM:

- **Sprint 1 — Dados e Persistência**: modelação de dados, mapeamento objeto-relacional com Hibernate, aplicação Java/Maven.
- **Sprint 2 — API REST**: desenvolvimento de uma API RESTful com Spring Boot, testada com Postman e documentada com OpenAPI.
- **Sprint 3 — Cliente JavaFX**: aplicação cliente com interface gráfica em JavaFX, integrada com a API REST.
